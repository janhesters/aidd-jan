# Better Auth Integration Plan

## New Packages

### 1. `packages/email` (`@workspace/email`)
- **`src/send-email.ts`** — Resend-based `sendEmail` utility (from the code you provided), adapted for the monorepo (zod for validation, React Email for rendering)
- **`src/templates/otp-email.tsx`** — OTP / magic code email template (React Email)
- **`package.json`** — deps: `@react-email/components`, `react`, `zod`
- **Exports**: `"."` → sendEmail, `"./templates"` → templates

### 2. `packages/auth` (`@workspace/auth`)
- **`src/index.ts`** — `betterAuth(...)` config:
  - `drizzleAdapter(db, { provider: "sqlite", schema })`
  - `emailOTP` plugin for passwordless email-based OTP sign-in
  - `plugins: [organization(), emailOTP({ sendVerificationOTP }), testUtils()]` (testUtils conditionally when NODE_ENV !== "production")
  - `sendVerificationOTP` wired to `@workspace/email` with the OTP template
  - ID generation via `@paralleldrive/cuid2` (`advanced: { generateId: () => createId() }`)
  - Export `auth`, `Session`/`User` types via `auth.$Infer`
- **`src/client.ts`** — `createAuthClient` from `better-auth/react` with `organizationClient` + `emailOTPClient` plugins
- **`package.json`** — deps: `better-auth`, `@workspace/db`, `@workspace/email`, `@paralleldrive/cuid2`
- **Exports**: `"."` → server auth config, `"./client"` → client auth

## Modified Packages

### 3. `packages/db` (`@workspace/db`)
- **`src/schema.ts`** (new) — CLI-generated auth tables: `user`, `session`, `account`, `verification`, + organization plugin tables. All using `sqliteTable` from `drizzle-orm/sqlite-core`.
- **`src/index.ts`** — Import `* as schema` and pass to `drizzle(client, { schema })`
- **`drizzle.config.ts`** — Add `schema: "./src/schema.ts"`
- **`package.json`** — Add `"./schema"` export, add `@paralleldrive/cuid2` dep

### 4. `apps/web`
- **`app/routes/api.auth.$.ts`** — Resource route: `loader` + `action` both delegate to `auth.handler(request)`
- **`app/lib/auth-client.ts`** — Re-export from `@workspace/auth/client` (or direct import)
- **`package.json`** — Add `@workspace/auth` dep (already has `@workspace/db`)
- **`.env.example`** — Add `BETTER_AUTH_SECRET`, `BETTER_AUTH_URL`, `RESEND_API_KEY`

### 5. Root / Turbo
- **`turbo.json`** — No new tasks needed (existing check:* tasks cover new packages automatically)
- **`bun install`** — Install all new deps

## Dependency Graph
```
apps/web → @workspace/auth → @workspace/db
                            → @workspace/email
         → @workspace/db (direct, for non-auth DB access)
```

## Key Decisions
- **No passwords** — email OTP only (via `emailOTP` plugin from `better-auth/plugins`)
- **cuid2 for IDs** — `@paralleldrive/cuid2` used in `advanced.generateId`
- **Organization plugin** — registered with defaults, no full org flows yet
- **testUtils plugin** — registered conditionally (`NODE_ENV !== "production"`)

## Execution Order
1. Install deps at root: `better-auth`, `@paralleldrive/cuid2`, `@react-email/components`, `react`, `zod` (where needed)
2. Create `packages/email` (standalone, no internal deps)
3. Add schema to `packages/db`, update drizzle config + index, add `"./schema"` export
4. Create `packages/auth` (depends on db + email)
5. Wire up `apps/web` (resource route, client, env vars, dep)
6. Run `npx auth generate` to verify/update schema if needed
7. Run `drizzle-kit generate` for initial auth migration
8. `bun run validate` → fix → commit → push

## Environment Variables (new)
- `BETTER_AUTH_SECRET` — 32+ char secret for signing (required)
- `BETTER_AUTH_URL` — App URL, e.g. `http://localhost:5173` locally
- `RESEND_API_KEY` — Resend API key (optional in dev, logs to console without it)
